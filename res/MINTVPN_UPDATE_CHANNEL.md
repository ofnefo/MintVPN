# MintVPN updates

MintVPN checks only https://api.github.com/repos/ofnefo/MintVPN/releases and looks for MintVPN- assets. An empty release list reports that no suitable new MintVPN release is available. Network errors are reported separately; there is no fallback to Quattro or another feed. No release is assumed to exist.

The current release can only be opened in a browser. In-app installation is disabled until updater, package layout, authenticity verification and rollback are verified. No real update was downloaded or installed by this change.
