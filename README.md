# MintVPN

MintVPN — настольный VPN-клиент для работы с подписками, серверами и правилами маршрутизации. Проект основан на [Throne](https://github.com/throneproj/Throne) и развивается самостоятельно.

Этот репозиторий содержит исходный код клиента и инструкции по сборке для Windows.

В приложении можно импортировать подписку, выбрать сервер, настроить прямые и проксируемые маршруты, системный прокси, TUN и DNS. Доступность режимов зависит от операционной системы и настроек сервера.

## Установка

Сборки для Windows, когда они опубликованы, находятся на [странице выпусков](https://github.com/ofnefo/MintVPN/releases). После установки добавьте свою подписку, выберите сервер и проверьте настройки маршрутизации перед подключением.

Перед обновлением или переносом сохраните резервную копию конфигурации и подписок. Если используете удалённый доступ, проверьте его после изменения маршрутов.

## Исходный код

Интерфейс написан на C++ с использованием Qt, сетевое ядро — на Go. Исходники интерфейса и ядра находятся в `src`, `include` и `core`. Скрипты сборки и упаковки находятся в `script`; требования и команды приведены в [инструкции по сборке для Windows](BUILD_WINDOWS.md).

`script/fetch_srslist.py` получает закреплённый каталог маршрутов и проверяет SHA-256. Личные подписки и настройки пользователя в репозиторий не входят.
