# MintVPN

MintVPN — настольный VPN-клиент с гибкой маршрутизацией приложений и сервисов. Можно выбирать, какой трафик отправлять через VPN, какой — напрямую, а какой — через отдельный прокси. Проект основан на [Throne](https://github.com/throneproj/Throne) и развивается самостоятельно.

Этот репозиторий содержит исходный код клиента и инструкции по сборке для Windows.

## Возможности

- **Маршрутизация по приложениям и сервисам:** отдельные правила для процессов, доменов и IP-адресов.
- **Разные пути подключения:** VPN, прямое соединение и отдельные прокси для выбранных правил.
- **Подписки и серверы:** импорт подписок, выбор сервера и автоматический выбор из группы.
- **Настройка подключения:** системный прокси, TUN, DNS, автозапуск и автоматическое подключение.

Доступность режимов зависит от операционной системы и настроек сервера.

## Установка

Установщик для Windows находится на [странице выпусков](https://github.com/ofnefo/MintVPN/releases). После установки добавьте свою подписку, выберите сервер и проверьте настройки маршрутизации перед подключением.

Перед обновлением или переносом сохраните резервную копию конфигурации и подписок. Если используете удалённый доступ, проверьте его после изменения маршрутов.

## Исходный код

Интерфейс написан на C++ с использованием Qt, сетевое ядро — на Go. Исходники интерфейса и ядра находятся в `src`, `include` и `core`. Скрипты сборки и упаковки находятся в `script`; требования и команды приведены в [инструкции по сборке для Windows](BUILD_WINDOWS.md).

`script/fetch_srslist.py` получает закреплённый каталог маршрутов и проверяет SHA-256. Личные подписки и настройки пользователя в репозиторий не входят.
